# SQUAD — тестовая версия

Статический тестовый сайт SQUAD на русском, узбекском и английском языках.

## Локальный просмотр

Из папки `site/`:

```bash
python3 -m http.server 4173
```

Открыть: `http://127.0.0.1:4173/index.html`

В первой версии есть главная, `/contacts.html`, локализованные legal-разделы и фирменная 404-страница. Юридические документы доступны по slash-маршрутам вида `/ru/terms/`, `/uz/privacy/`, `/en/consent/`.
